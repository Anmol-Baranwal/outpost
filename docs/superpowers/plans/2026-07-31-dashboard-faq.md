# FAQ Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the permanently-blank Frequently Asked panel into real FAQs generated from what the community actually keeps asking, with a human review gate before anything appears.

**Architecture:** A `Faq` model holds question/answer pairs with a DRAFT → PUBLISHED lifecycle. A weekly `FAQ_GENERATE` job sends recent ticket titles and first messages to Claude in one call, gets back clusters of repeated questions, and writes DRAFT rows. The dashboard panel reads PUBLISHED only; admins promote or discard drafts from the same panel.

**Tech Stack:** Prisma + PostgreSQL, Anthropic SDK (Claude), Postgres job queue, Next.js 15 App Router, React 19, Vitest.

This is PR 3 of three from `docs/superpowers/specs/2026-07-31-dashboard-usability-design.md`. Branch: `feat/dashboard-faq`, cut fresh off `main` — independent of PRs 1 and 2.

## Global Constraints

- The corpus is **all tickets regardless of status**, not resolved-only. Zero tickets have ever been RESOLVED or CLOSED, so a resolved-only corpus produces the same blank panel with more machinery behind it.
- Clustering uses **Claude directly, no embeddings**. Outpost's schema has no embedding column and no vector infrastructure — the pgvector image in `docker-compose.yml` serves Pathfinder's separate KB database. At 51 tickets one call is cheaper and simpler than adding vector search. The 200-ticket cap is where that reasoning should be revisited.
- The panel shows **PUBLISHED only**. An AI-written wrong answer must not reach the dashboard without a human promoting it.
- A generation run **never mutates** rows already PUBLISHED or DISCARDED. Re-running must not resurrect something a human rejected.
- A malformed model response **fails the job loudly**. Never write partial or garbage drafts.
- Every code change ships with a test. No exceptions.

```prisma
/// FAQ_GENERATE job from clusters of tickets asking the same thing.

/// Drafts are never shown on the dashboard — a human promotes them first,
/// so an AI-written wrong answer cannot become the canonical FAQ.

    clusterSize     Int

    sourceTicketIds Json

    reviewedAt      DateTime?
    createdAt       DateTime  @default(now())
    updatedAt       DateTime  @updatedAt

}

enum FaqStatus {
    DRAFT
    PUBLISHED
    DISCARDED
}
```

```typescript
import Anthropic from '@anthropic-ai/sdk';
import { config } from './config.js';

/** A ticket as fed to the clusterer. */
export interface FaqTicketInput {
    id: string;
    title: string;
    firstMessage: string;
    aiAnswer: string | null;
}

/** A group of tickets asking the same underlying question. */
export interface FaqCluster {
    question: string;
    answer: string;
    ticketIds: string[];
}

/** Below this, a "cluster" is just one person's question, not an FAQ. */
export const MIN_CLUSTER_SIZE = 2;

/**
 * Cap on tickets per run. At this scale a single Claude call is cheaper and
 * simpler than embeddings plus vector search; past it, revisit that choice.
 */
export const MAX_TICKETS_PER_RUN = 200;

const SYSTEM_PROMPT = `You group support tickets that ask the same underlying question, for an FAQ.

Respond with ONLY a JSON object, no markdown and no explanation:

{
  "clusters": [
    {
      "question": "<the shared question, phrased as a user would ask it>",
      "answer": "<a canonical answer, grounded in the provided AI answers>",
      "ticketIds": ["<id>", "<id>"]
    }
  ]
}

Rules:
- Only group tickets that share the same underlying question. Two tickets about "threads" are NOT the same question unless they ask the same thing about threads.
- A group needs at least 2 tickets. Do not emit single-ticket groups.
- Ground each answer in the AI answers provided. Do not invent APIs, flags, or behaviour that does not appear in them.
- If no tickets group, return {"clusters": []}.`;

/** Parse the model's reply. Throws on anything malformed — a bad response must fail the job, not write garbage drafts. */
export function parseClusterResponse(text: string): FaqCluster[] {
    const cleaned = text.trim().replace(/^```(?:json)?\s*/i, '').replace(/\s*```$/, '');

    let parsed: unknown;
    try {
        parsed = JSON.parse(cleaned);
    } catch {
        throw new Error(`FAQ clusterer returned non-JSON: ${text.slice(0, 200)}`);
    }

    const clusters = (parsed as { clusters?: unknown }).clusters;
    if (!Array.isArray(clusters)) {
        throw new Error('FAQ clusterer response has no clusters array');
    }

    return clusters
        .map((raw, i) => {
            const c = raw as Partial<FaqCluster>;
            if (
                typeof c.question !== 'string' ||
                typeof c.answer !== 'string' ||
                !Array.isArray(c.ticketIds)
            ) {
                throw new Error(`FAQ cluster ${i} is missing question, answer, or ticketIds`);
            }
            return { question: c.question, answer: c.answer, ticketIds: c.ticketIds };
        })
        .filter((c) => c.ticketIds.length >= MIN_CLUSTER_SIZE);
}

/** Groups recurring questions across tickets using one Claude call. */
export class FaqClusterer {
    private client: Anthropic;
    private model: string;

    constructor(options?: { apiKey?: string; model?: string }) {
        this.client = new Anthropic({
            apiKey: options?.apiKey ?? config.anthropicApiKey,
        });
        this.model = options?.model ?? config.classifierModel;
    }

    async cluster(tickets: FaqTicketInput[]): Promise<FaqCluster[]> {
        if (tickets.length < MIN_CLUSTER_SIZE) return [];

        const corpus = tickets
            .slice(0, MAX_TICKETS_PER_RUN)
            .map((t) =>
                [
                    `id: ${t.id}`,
                    `title: ${t.title.slice(0, 200)}`,
                    `question: ${t.firstMessage.slice(0, 800)}`,
                    t.aiAnswer ? `answer_given: ${t.aiAnswer.slice(0, 800)}` : 'answer_given: none',
                ].join('\n'),
            )
            .join('\n---\n');

        const message = await this.client.messages.create({
            model: this.model,
            max_tokens: 4096,
            temperature: 0.1,
            system: SYSTEM_PROMPT,
            messages: [{ role: 'user', content: corpus }],
        });

        const text = message.content[0].type === 'text' ? message.content[0].text : '';
        return parseClusterResponse(text);
    }
}
```

```typescript
/**
 * FAQ_GENERATE job handler.
 *
 * Sends recent tickets to the clusterer, then writes one DRAFT Faq per
 * cluster of repeated questions.
 *
 * Rows already PUBLISHED or DISCARDED are never modified: a re-run must not
 * resurrect an answer a human rejected, nor silently rewrite a published one.
 */

import { prisma } from '@copilotkit/outpost/db';
import { FaqClusterer, MAX_TICKETS_PER_RUN } from '@copilotkit/outpost/ai';
import type { FaqTicketInput } from '@copilotkit/outpost/ai';
import type { JobHandler } from '../types.js';
import { JobType } from '../types.js';

export interface FaqGenerateSummary {
    ticketsScanned: number;
    clustersFound: number;
    draftsCreated: number;
    skippedExisting: number;
}

/** Loose match so trivial rewordings don't produce duplicate drafts. */
function normalizeQuestion(question: string): string {
    return question.toLowerCase().replace(/[^a-z0-9 ]/g, '').replace(/\s+/g, ' ').trim();
}

export const handleFaqGenerate: JobHandler<typeof JobType.FAQ_GENERATE> = async (
    payload,
    context,
) => {
    const limit = payload.limit ?? MAX_TICKETS_PER_RUN;

    const tickets = await prisma.ticket.findMany({
        take: limit,
        orderBy: { createdAt: 'desc' },
        select: {
            id: true,
            title: true,
            messages: {
                select: { content: true, type: true, isAiGenerated: true },
                orderBy: { createdAt: 'asc' },
            },
        },
    });

    const inputs: FaqTicketInput[] = tickets.map((t) => ({
        id: t.id,
        title: t.title,
        firstMessage: t.messages.find((m) => m.type === 'USER')?.content ?? '',
        aiAnswer: t.messages.find((m) => m.isAiGenerated)?.content ?? null,
    }));

    // A parse failure propagates: a malformed model response must fail the
    // job, not write partial drafts.
    const clusters = await new FaqClusterer().cluster(inputs);

    // Every existing question, whatever its status — a DISCARDED question
    // must not come back as a fresh draft next week.
    const existing = await prisma.faq.findMany({ select: { question: true } });
    const seen = new Set(existing.map((f) => normalizeQuestion(f.question)));

    let draftsCreated = 0;
    let skippedExisting = 0;

    for (const cluster of clusters) {
        if (seen.has(normalizeQuestion(cluster.question))) {
            skippedExisting++;
            continue;
        }

        await prisma.faq.create({
            data: {
                question: cluster.question,
                answer: cluster.answer,
                status: 'DRAFT',
                clusterSize: cluster.ticketIds.length,
                sourceTicketIds: cluster.ticketIds,
            },
        });

        seen.add(normalizeQuestion(cluster.question));
        draftsCreated++;
    }

    const summary: FaqGenerateSummary = {
        ticketsScanned: inputs.length,
        clustersFound: clusters.length,
        draftsCreated,
        skippedExisting,
    };

    context.log?.(`[FAQ_GENERATE] ${JSON.stringify(summary)}`);

    return summary;
};
```

```typescript
import { NextResponse } from 'next/server';
import { getServerSession } from 'next-auth/next';
import { authOptions } from '@/lib/auth';
import { prisma } from '@copilotkit/outpost/db';

/**
 * GET /api/dashboard/faq[?status=DRAFT]
 *
 * PUBLISHED entries by default — drafts never reach the dashboard, so an
 * AI-written wrong answer cannot appear without a human promoting it.
 * Requesting drafts requires ADMIN.
 */
export async function GET(request: Request) {
    const session = await getServerSession(authOptions);
    if (!session?.user) {
        return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const wantsDrafts = new URL(request.url).searchParams.get('status') === 'DRAFT';
    const role = (session.user as Record<string, unknown>).role;

    if (wantsDrafts && role !== 'ADMIN') {
        return NextResponse.json({ error: 'Forbidden' }, { status: 403 });
    }

    try {
        const rows = await prisma.faq.findMany({
            where: { status: wantsDrafts ? 'DRAFT' : 'PUBLISHED' },
            orderBy: { clusterSize: 'desc' },
        });

        return NextResponse.json({
            entries: rows.map((row) => ({
                id: row.id,
                question: row.question,
                answer: row.answer,
                sourceCount: row.clusterSize,
            })),
        });
    } catch (error) {
        console.error('[GET /api/dashboard/faq] Error:', error);
        return NextResponse.json({ error: 'Internal server error' }, { status: 500 });
    }
}
```
